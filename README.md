# Learning Java ☕

A structured repository covering **Java programming fundamentals to Object-Oriented Programming**, implemented through well-organized and progressively designed programs.

This repository is intended for beginners and intermediate learners who want strong clarity in **Java syntax, logic building, and core programming concepts**.

---

## 📌 Prerequisites

Before running these programs, ensure you have:

* **Java Development Kit (JDK)** installed (**JDK 8 or above recommended**)
* A **command-line terminal**
  * Linux/macOS → Terminal
  * Windows → Command Prompt / PowerShell / VS Code terminal
* *(Optional)* An IDE like **IntelliJ IDEA**, **Eclipse**, or **VS Code** with Java extension

---

## 📥 Installation & Setup

### 🔹 Clone the Repository

```sh
git clone https://github.com/AdityaSah2030/LearningJava.git
cd LearningJava
```

### 🔹 Compile a Program

```sh
javac 01_DataTypes_IO_Scanner.java
```

### 🔹 Run the Program

```sh
java _01_DataTypes_IO_Scanner
```

> **Note:** The class name in the file starts with `_` to allow numeric prefixes (e.g. `_01_DataTypes_IO_Scanner`). Use the exact class name when running.
